## Reflection Answers
1. **GitLens Blame View:** GitLens blame view helped me understand who made each change, what they changed, and when the change was made. This made it easier to track the history of code written by someone else.
2. **Live Share Pair Programming:** One advantage of Live Share is that both partners can work on the same code in real time, even from different locations. One limitation is that it can be less convenient than sitting together because communication depends on the internet.
3. **Collaborative Commits in a Portfolio:** Employers may value collaborative commits because they show that a candidate can work effectively with others, use Git properly, and contribute to a shared software project. It provides evidence of real teamwork rather than just individual work.
